# Semana 6 — Integração completa

**Entregável:** aplicação funcional. ✅

O fluxo completa o ciclo **orçamento → cesta → comparação → cardápio** em um só site:

1. **Cesta:** orçamento, pessoas, período e restrições ([tópicos 2](../desenvolvimento/02-otimizador.md) e [19](../desenvolvimento/19-trocar-e-em-casa.md)).
2. **Comparação:** um × dois mercados, com o deslocamento ([3](../desenvolvimento/03-comparacao-mercados.md)) e mercados por perto ([13](../desenvolvimento/13-localizacao-proteinas.md), [16](../desenvolvimento/16-configuracoes-raio.md)).
3. **Cardápio:** só com o que está na cesta ([18](../desenvolvimento/18-cardapio-seguro.md)).
4. **Chat:** agentes com RAG ([7](../desenvolvimento/07-llm-ferramentas.md), [9](../desenvolvimento/09-agentes.md)).
5. **Cupom:** QR code da NFC-e ([10](../desenvolvimento/10-nfce-multimodal.md)).

**Como rodar:** [guia de desenvolvimento](../desenvolvimento/README.md#como-rodar). **Como publicar:** [tópico 12](../desenvolvimento/12-publicacao.md).
